# Contribuir

Gracias por echar una mano.

- **Errores:** abre una issue con la plantilla «Error». Incluye versión, Windows y, si puedes, el log.
- **Ideas:** abre una issue con la plantilla «Idea» antes de ponerte a programar, para ver si encaja.
- **Pull requests:** pequeños y de un solo tema. Que compile sin avisos nuevos (`dotnet build`)
  y, si tocas la interfaz, añade una captura del antes y el después.

La documentación y los textos de la interfaz están en español.
